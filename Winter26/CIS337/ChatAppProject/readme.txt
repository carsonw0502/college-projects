Instructions:
1) Download and unzip the folder
2) Run the server.py file first (open with python in file explorer or the command "python (file name/path)" in a terminal)
3) Run the client.py files second (same steps as server), open as many clients as needed
4) Type messages on each client
5) Type 'end' in the "Enter message: " prompt to close the connection. It will only close either the client or server depending on which window it is typed in.

localhost is used to run both on the same machine, but the 'address' variable can be modified for use on multiple machines.
